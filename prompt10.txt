## COLLECTIONS — COMPLETE SYSTEM

### Overview

Per-profile saved game configurations. Two flavors:
- **Original collections** — created by the user, editable.
- **Clones (Pointers)** — a reference to a published collection by someone else. **Read-only.** Stored in a `collection_clones` join table, NOT duplicated as a new row.

"Other Collections" tab shows all public collections, with a `+`/`−` toggle to clone/unclone.

### Database schema

**`collections`:** id, profile_id, name, is_public, cover_kind, cover_r2_key, levels (JSON), years (JSON), genres_ids (JSON), artists_ids (JSON), created_at, updated_at.

**`collection_rounds`:** collection_id, position, level, question_types (JSON), answer_mode, mode, rounds, reversed_answers, reversed_audio, instruments, timer.

**`collection_clones`:** profile_id, collection_id, created_at. PRIMARY KEY (profile_id, collection_id).

**`source_id`** on `collections` is deprecated. Ignore it.

### v76 multiplayer flow (Collections → Multiplayer)

**The hook `useCollectionMultiplayer`** encapsulates the entire state machine:

```js
const {
  multiplayerCollection,
  openMultiplayerFor,   // (collection, { onCloseReadOnly }) → seeds settings + opens modal
  closeMultiplayer,
  startMultiplayer,     // ({ names, level, roundsPerPlayer }) → builds payload + navigates
} = useCollectionMultiplayer();
```

**`openMultiplayerFor(collection)`** does:
1. Finds the seed round (by smallest available level, or any round as fallback)
2. Calls `settings.applySettings(seedRound settings)` — hydrates `GameSettingsContext`
3. Calls `onCloseReadOnly()` if provided (closes the read-only modal)
4. Sets `multiplayerCollection` state

**`startMultiplayer({ names, level, roundsPerPlayer })`** does:
1. Resolves the target round by `level` (`rounds.find(r => Number(r.level) === Number(effectiveLevel))`)
2. Builds payload from `collection.genresIds`, `collection.artistsIds`, `collection.years`, `targetRound.*`
3. Writes to `sessionStorage['game.lastPlayParams']`
4. Clears `multiplayerCollection` and navigates to `/play-multi`

**Wiring in `LibraryPage.jsx` and `CollectionsModal.jsx`:**
