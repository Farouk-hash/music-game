## D1 Schema

```sql
CREATE TABLE genres (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  display_name TEXT NOT NULL,
  image TEXT,
  is_customized INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE artists (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  genre_ids TEXT NOT NULL DEFAULT '[]',     -- JSON array of ints
  image TEXT,
  tracks_count INTEGER NOT NULL DEFAULT 0,
  is_customized INTEGER NOT NULL DEFAULT 0,
  source TEXT NOT NULL DEFAULT 'matb3aa',   -- 'matb3aa' | 'albumaty' | 'mp3quran' | 'manual'
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_artists_source ON artists(source);

CREATE TABLE tracks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  artist_id INTEGER,
  r2_key TEXT,                -- forward rendition (nullable)
  r2_reversed_key TEXT,       -- reversed rendition (nullable)
  position TEXT,              -- start | middle | end | custom
  label TEXT,
  album_name TEXT,
  featured_artists TEXT       -- comma-separated names, nullable
);
CREATE UNIQUE INDEX idx_tracks_unique_clip ON tracks(artist_id, name, position);

CREATE TABLE lyrics (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  artist_id     INTEGER NOT NULL,
  track_name    TEXT    NOT NULL,
  lyrics        TEXT,
  created_at    TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at    TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE UNIQUE INDEX idx_lyrics_unique ON lyrics(artist_id, track_name);

CREATE TABLE album_years (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  artist_id     INTEGER NOT NULL REFERENCES artists(id) ON DELETE CASCADE,
  album_name    TEXT    NOT NULL,
  released_year INTEGER NOT NULL,
  created_at    TEXT    NOT NULL DEFAULT (datetime('now')),
  updated_at    TEXT    NOT NULL DEFAULT (datetime('now'))
);
CREATE UNIQUE INDEX idx_album_years_unique ON album_years(artist_id, album_name);
```

**Key semantics:**
- One `tracks` row = one **slot** = `(artist_id, name, position)`. Forward + reversed renditions on the same row.
- One `album_years` row = one **album** = `(artist_id, album_name)`. `album_name` stored **as it appears in `tracks.album_name`**.
- `released_year` is **NOT NULL**.
- Custom artists use IDs in 90000+ with `is_customized = 1`. Albumaty-created artists get random IDs in 90000–99999 with `source = 'albumaty'`.

## Route Dispatch Gotcha

`src/routes/index.js` uses **named capture groups** `(?<id>\d+)`. Regex `groups` objects have a null prototype — `Number(params)` throws `Cannot convert object to primitive value`. Two fixes already applied:
1. `const params = { ...(match.groups ?? {}) };` in `matchRoute`
2. Handlers pass `params.id` (scalar), not `params` (object)

**Route order matters:** static paths (`/stats`, `/by-artist`, `/bulk`) MUST be registered before parameterized ones (`/:id`).

## Express Proxy (`/api/cloudflare/*`)

Mirrors every Worker route above. `cloudflare.get/post/put/delete(path, body?)`.

**Publish endpoints:**
```
POST /tracks/publish-clip       single slot, forward + optional reversed
POST /tracks/publish-clips      batch — clips[] each = one slot with forward/reversed flags
POST /tracks/publish-upload     multipart, 1-3000 files, per-position config
POST /tracks/:id/reverse        reverse existing forward → attach as reversed
```

**`publishAndSaveSlot`** (in `server/routes/cloud-flare-routes/clips.js`): given `{ trackId, sourceSrc, name, artistId, position, duration, forward, reversed, albumName, releasedYear, featuredArtists, source }`, calls `publishClip` per rendition, then POSTs ONE `/tracks` row with both keys. On 409, fetches existing and PUTs to merge. Also does a **best-effort `album_years` upsert** if `albumName` + `releasedYear` are provided.

## R2 Key Structure

```
clips/track-{trackId}-{position}-{N}s.mp3             (music, forward)
clips/track-{trackId}-{position}-{N}s-rev.mp3         (music, reversed)
clips/quran/track-{trackId}-{position}-{N}s[-rev].mp3
clips/upload/track-{trackId}-{position}-{N}s[-rev].mp3
```

For `custom` position, key includes start offset: `...-custom-{startSec}s-{durationSec}s[-rev].mp3`.

`trackId` for uploads: `9000000 + (Date.now() % 1000000) + fileIndex`. Not the DB row id.

## FFmpeg Pipeline

`publishClip` (in `server/lib/publish-clip.js`) produces ONE rendition and uploads to R2. Does NOT write to D1.

- **Forward:** `-ss {startSec} -i {in} -t {dur} -acodec libmp3lame -ab 24k -ac 1 -ar 22050 -compression_level 9 -y {out}`
- **Reversed:** `-ss {startSec} -i {in} -af "atrim=duration={dur},areverse" ... ` (the `-t` is replaced by the atrim filter so `areverse` sees exactly N seconds)

`reverseExistingClip` takes an existing forward R2 key, downloads via `/clips/serve?key=`, runs `-i {in} -af areverse`, uploads to `&reversed=1`.

## Pipelines

### Lyrics pipeline
`server/scripts/pipeline/run.js` — orchestrator. Sources: matb3aa + lyrics.nu. Compares, bulk upserts into `lyrics`. Emits JSON progress lines.

### Album-years pipeline
`server/scripts/pipeline/album-years.js` — orchestrator. Given `[{ artist_id, artist_name, album_names: [...] }]`, resolves years via matb3aa + albumaty fallback chain, bulk upserts into `album_years`.

**Fallback chain** (first hit wins):
- Prefixed (`البوم` in name): matb3aa clean → albumaty clean → albumaty raw → albumaty+ألبوم → albumaty+البوم
- Non-prefixed: albumaty raw → albumaty clean → albumaty+ألبوم → albumaty+البوم → matb3aa raw → matb3aa clean → matb3aa+ألبوم → matb3aa+البوم

### Albumaty crawl + publish

`server/lib/albumaty-publish.js` — `ensureArtist({...})`, `publishOneTrack({ albumatySongId, name, artistId, albumName, releasedYear, source })`. Passes `released_year` through to `publish-clips`.
