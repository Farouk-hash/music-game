## Instrumental Pipeline — WORKING END-TO-END

**Purpose:** for selected artists, cut two 10-second instrumental clips (middle + custom) per track, upload to R2 + D1, delete local files.

### Locked decisions

| Aspect | Value |
|---|---|
| Source audio | `t.src` from matb3aa artist catalogue |
| Segment length | **10 seconds** |
| Placements | **`middle` @ 48%, `custom` @ 52%** |
| Output format | **MP3, 64 kbps, mono, 44.1 kHz** |
| Instrument genre ID | **6** (fixed) |
| `genre_ids` shape | `[6, ...artist_genres]` |
| R2 folder | `instrumentals/<artist_slug>/<track_slug>/<middle\|custom>.mp3` |
| Local output root | `E:\matb3aa-game\server\instrumental-output\<artist_id>_<slug>\<track_slug>\` |
| Job model | One job per batch |

### Two-phase pipeline

**Phase 1 — Generate** (`server/scripts/instrumental/batch.js`):
```
1. Download full song → source.mp3
2. ffprobe → duration
3. For each placement (middle 48%, custom 52%):
    a. ffmpeg cut 10s raw WAV slice (stereo, 44.1kHz)
    b. python -m demucs --two-stems=vocals on the 10s slice
    c. ffmpeg convert no_vocals.wav → mono MP3 (64k)
4. Write meta.json
```
**Time:** ~1 min per track on CPU.

**Phase 2 — Upload** (`server/scripts/instrumental/upload.js`):
```
1. Read meta.json + MP3 paths
2. For each segment:
    a. PUT /instrumentals/upload?key=…  (bytes)
    b. Collect D1 row: { artist_id, track_name, position, r2_key, album_name, genre_ids }
       ← NO source_url
3. POST /instruments/bulk  { items: [...] }
4. On success: delete local seg_*.mp3 (keep meta.json)
```
**Time:** ~1 second per track.
