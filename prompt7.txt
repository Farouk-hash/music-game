### Action types

| Type | Who | Params | Effect |
|---|---|---|---|
| `ready` | Non-host, lobby | `{ ready: bool }` | Toggle ready |
| `start` | Host, lobby | — | Sets `phase='loading'`, kicks off fetch in background |
| `answer` | Any active player | `{ typed }` | Records answer for `room.q_index`; rejected if a row already exists |
| `advance` | Host, reveal | — | `reveal` → next `question`, or → `finished` |
| `leave` | Any | — | See leave behaviour below |
| `reset` | Host, finished/lobby | — | Clear, → `lobby` |
| `rejoin` | Any marked `left` | — | Flips `left=0`; conditionally resets `locked` |

### Leave behaviour

```js
async #leave(player, room) {
  const sql = this.ctx.storage.sql;

  if (room.phase === 'lobby') {
    sql.exec('DELETE FROM players WHERE id = ?', player.id);

    const remaining = sql.exec('SELECT COUNT(*) AS n FROM players').one().n;
    if (remaining === 0) {
      await this.ctx.storage.deleteAll();
      return { ok: true, version: 0 };
    }

    if (player.is_host) this.#promoteNextHost();
  } else {
    // In-game: mark as left. `locked` is NOT touched.
    sql.exec('UPDATE players SET left = 1 WHERE id = ?', player.id);
    if (player.is_host) {
      sql.exec('UPDATE players SET is_host = 0 WHERE id = ?', player.id);
      this.#promoteNextHost();
    }
  }

  this.#touchExpiry();
  const version = this.#bumpVersion();

  // Mode 2: if all remaining active players have answered, end the question.
  if (room.phase === 'question') {
    const total = sql.exec('SELECT COUNT(*) AS n FROM players WHERE left = 0').one().n;
    const answered = sql.exec(
      `SELECT COUNT(*) AS n FROM answers a
        JOIN players p ON p.id = a.player_id
       WHERE a.q_idx = ? AND p.left = 0`,
      room.q_index
    ).one().n;
    if (total > 0 && answered >= total) await this.#endQuestion();
  }

  return { ok: true, version };
}
```

### Leave outcomes

| Scenario | Result |
|---|---|
| Host alone, closes modal or tab | Room destroyed (`deleteAll()`) |
| Host + guests, host leaves | Earliest-joined guest becomes host |
| Guest leaves | No promotion |
| Host leaves mid-game | Earliest-joined active player becomes host, game continues |
| Guest joins a destroyed code | 404 `Room not found` |
| Player refreshes mid-game | Beacon fires → `left=1` → client auto-rejoins (`rejoin`) on mount |
| `#getRoom` when table is gone | Returns `null` via try/catch → `getState` responds with `{ ok: false, error: 'Room not found' }` (HTTP 404) |

### `#rejoin`

```js
async #rejoin(player, room) {
  if (!player.left) return { ok: true, version: room.version };

  const inQuestion = room.phase === 'question';
  const existingAnswer = inQuestion
    ? this.ctx.storage.sql.exec(
        'SELECT 1 FROM answers WHERE player_id = ? AND q_idx = ? LIMIT 1',
        player.id, room.q_index
      ).toArray()
    : [];
  const hasAnsweredCurrent = existingAnswer.length > 0;

  const activeHost = this.ctx.storage.sql.exec(
    'SELECT id FROM players WHERE is_host = 1 AND left = 0 LIMIT 1'
  ).toArray();

  const shouldClearHostFlag =
    player.is_host && activeHost.length > 0 && activeHost[0].id !== player.id;

  const lockedValue = hasAnsweredCurrent ? 1 : 0;

  const setClauses = [
    'left = 0',
    `locked = ${lockedValue}`,
    shouldClearHostFlag ? 'is_host = 0' : null,
  ].filter(Boolean).join(', ');

  this.ctx.storage.sql.exec(
    `UPDATE players SET ${setClauses} WHERE id = ?`,
    player.id
  );

  this.#touchExpiry();
  const version = this.#bumpVersion();
  return { ok: true, version };
}
```

### `#answer` — existing-answer guard

```js
async #answer(player, room, action) {
  if (room.phase !== 'question') return { ok: false, error: 'Not in question phase' };
  if (player.locked) return { ok: false, error: 'Already answered this question' };

  const existing = this.ctx.storage.sql.exec(
    'SELECT 1 FROM answers WHERE player_id = ? AND q_idx = ? LIMIT 1',
    player.id, room.q_index
  ).toArray();
  if (existing.length > 0) {
    this.ctx.storage.sql.exec('UPDATE players SET locked = 1 WHERE id = ?', player.id);
    return { ok: false, error: 'Already answered this question' };
  }

  // …rest unchanged…
}
```

### `handleAction` gate

```js
async handleAction(playerId, action) {
  const room = this.#getRoom();
  if (!room) return { ok: false, error: 'Room not found' };

  const player = this.#getPlayer(playerId);
  if (!player) return { ok: false, error: 'Player not in this room' };

  const type = action?.type;

  // `rejoin` is allowed even when the player is marked left.
  if (type !== 'rejoin' && player.left) {
    return { ok: false, error: 'Player has left' };
  }

  if (type === 'ready')   return this.#ready(player, room, action);
  if (type === 'start')   return this.#start(player, room);
  if (type === 'answer')  return this.#answer(player, room, action);
  if (type === 'advance') return this.#advance(player, room);
  if (type === 'leave')   return this.#leave(player, room);
  if (type === 'reset')   return this.#reset(player, room);
  if (type === 'rejoin')  return this.#rejoin(player, room);

  return { ok: false, error: `Unknown action: ${type}` };
}
```

### `#promoteNextHost`

```js
#promoteNextHost() {
  const sql = this.ctx.storage.sql;

  const alreadyHost = sql
    .exec('SELECT id FROM players WHERE is_host = 1 AND left = 0 LIMIT 1')
    .toArray();
  if (alreadyHost.length > 0) return;

  // Clear stale is_host flags before assigning the new host.
  sql.exec('UPDATE players SET is_host = 0 WHERE is_host = 1');

  const next = sql
    .exec('SELECT id FROM players WHERE left = 0 ORDER BY rowid ASC LIMIT 1')
    .toArray();
  if (next[0]) {
    sql.exec('UPDATE players SET is_host = 1 WHERE id = ?', next[0].id);
  }
}
```

## host-sporcle-wrangler — response.js (status handling)

**Important:** `json()` accepts a bare number as the second argument.

```js
export function json(data, init = {}) {
  const normalized = typeof init === 'number' ? { status: init } : init;
  return Response.json(data, {
    ...normalized,
    headers: { ...CORS_HEADERS, ...(normalized.headers || {}) },
  });
}
```

**Why:** earlier, calls like `json(result, result.ok ? 200 : 404)` passed a bare number. `Response.json` ignored it (defaulted to 200). Now the number is normalized to `{ status }`.

Also — the client-side `sporcleApi.request` throws on `{ ok: false }` even with a 2xx status, as a defense in depth:

```js
if (body && typeof body === 'object' && body.ok === false) {
  const err = new Error(body.error ?? 'Request failed');
  err.status = res.status;
  err.body = body;
  throw err;
}
```

## Sporcle Client — Key Design Decisions

**Long-poll driven.** `useHostSporcle` loops `GET /state?since=N`. The DO holds the request ~3s when version is unchanged.

**Overlays driven by server timestamps.** `CountdownOverlay` takes `endsAt` and computes `remaining = endsAt - Date.now()` on every 100ms tick.

**`refresh()` aborts in-flight polls.** After any action, `useHostSporcleActions` calls `onVersion` → `refresh()`.

**State hoisting — single polling loop.** `SporcleModal` does NOT call `useHostSporcle`. Play owns the polling loop and passes `state`, `actions`, `myId` down.

**`RoomPanel` is presentational.** Renders by phase: lobby (roster + ready/start), loading (spinner), countdown (countdown card).

**`SporcleProgress`** shows per-player correctness history. Fed by `answersByQ`, accumulated on Play from each `state.reveal` payload.

**Play.jsx board split:**
- `question` phase → `PlayerRoster` (locked state — who's answered)
- `reveal` phase → `SporcleProgress` (correctness history)
- **Both** dim and strike-through players marked `left: true`.

**Mid-game rejoin — the `isLocked` guard.**
Play.jsx computes `isLocked = !!me?.locked`. `handlePick` refuses when `isLocked`. `QuestionPanel` accepts an `isLocked` prop that feeds `hasAnswered`, so the "Locked in" hint shows.
DO side: `#rejoin` sets `locked` based on whether the player already answered the current question. `#answer` also checks the `answers` table as a safety net.

**Auto-rejoin on refresh.** Play.jsx has a ref-guarded effect that calls `actions.rejoin(myId)` if the local player is `left: true`. Prevents refresh-kicks-you-out.

**Leave beacon on tab close.** `beforeunload` → `sporcleApi.leaveBeacon(code, myId)`. **Unreliable on mobile Safari** — the mobile case leaves the player marked as active until the room expires.
