## SPORCLE — TIE BREAKER + ALL-ANSWERED FIX (v67)

### Tie Breaker (implemented)

**Server-side (`host-sporcle.js`):**
- `tie_breaker INTEGER NOT NULL DEFAULT 0` on `room` table.
- `#checkTieBreaker(room)` fetches 3 questions. If top score is tied, it locks non-tied players (`locked = 1`), sets `tie_breaker = 1`, and starts the first question with a 15-second timer.
- `#advance` and `alarm` handle the loop: if still tied after 1 question, advance to next pre-fetched question. If 3 exhausted, fetch a new batch.
- `#endQuestion` forces speed-mode scoring during tie-breaker (first correct +1).
- `#answer` also forces end-on-first-correct during tie-breaker.
- Non-tied players can't answer (they were locked).

**Client-side (`Play.jsx`, `Result.jsx`):**
- `Play.jsx` shows a red "Sudden Death" banner when `state.isTieBreaker` is true.
- Timer switches to 15s. Host button text changes to "Show final winner".
- `Result.jsx` shows "Won by Sudden Death" under the winner's name.

### All-Answered Fix (implemented in v67)

**Bug:** In **Speed mode**, if all players answered wrong, the round waited for the 20-second timer instead of ending immediately.

**Cause:** The `if (answered >= total)` check in `#answer` was inside `if (room.mode === 'collect')`. So in speed mode, "all wrong" never triggered the end-of-question logic.

**Fix:** The "all answered" check is now outside the mode conditional. It runs after the "first correct ends" check in **both** modes (and tie-breaker). So in speed mode, if nobody got it right, the last wrong answer ends the round immediately.

### Inference Timing (CPU)

- **10 steps, 20-second clip:** ~1.5 min (diffusion) + ~1.5 min (VAE decode) = **~3 min total**.
- **15 steps, 30-second clip:** ~7 min total.
- **60 steps, 30-second clip:** ~30 min.
- **Full 3-minute clip:** crashes with OOM during VAE decode (even with pagefile fix).

**For testing/production, use 20–30 second clips with `inference_steps: 10`.**

### Known ACE-Step pitfalls

- **`hf_xet` deadlocks:** Fix with `set HF_HUB_DISABLE_XET=1` before starting the API server.
- **Unauthenticated rate limit:** Fix by saving token to `C:\Users\Desktop\.cache\huggingface\token`.
- **`transformers` OSError:** Missing `model.safetensors`. Download the correct repo.
- **`libtorchcodec_core*.dll` error:** FFmpeg static, not shared. Install full-shared FFmpeg.
- **CPU only:** `torch.cuda.is_available()` is False → generation takes 5–30 minutes per cover.
- **Paging file too small:** Increase to 32 GB and restart.
- **`WinError 10061` during polling:** API server crashed (usually OOM). Trim audio or lower `inference_steps`.
- **VAE decode OOM:** Even after diffusion, the VAE decode on a full 3-min track crashes. Use 20–30 sec clips.
