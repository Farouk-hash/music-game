## MATB3AA MEDIA URL MIGRATION (v72)

### The bug

matb3aa migrated from `/media/<file>.mp3` to **`/storage/media/<file>.mp3`** when they moved to a BeMusic-powered SPA. Old URLs return `200 text/html` (SPA shell). `download()` in `server/scripts/instrumental/batch.js` silently saved HTML to `source.mp3`. `ffprobe` failed with "Failed to find two consecutive MPEG audio frames."

### The fix

`absolutizeSrc()` in `batch.js` **normalizes any input** to `https://www.matb3aa.com/storage/media/<file>`:

```js
function absolutizeSrc(src) {
  if (!src) return null;
  const base = (MATB3AA_AUDIO_BASE || 'https://www.matb3aa.com').replace(/\/$/, '');
  if (/^https?:\/\//i.test(src)) {
    const filename = src.replace(/^https?:\/\/[^/]+\//i, '');
    const pathOnly = filename.replace(/^(storage\/)?media\//i, '');
    return `${base}/storage/media/${encodeURIComponent(decodeURIComponent(pathOnly))}`;
  }
  const filename = src.replace(/^(storage\/)?media\//i, '').replace(/^\//, '');
  return `${base}/storage/media/${encodeURIComponent(decodeURIComponent(filename))}`;
}
```

### Strict audio validation in `download()`

Rejects non-audio BEFORE saving:
- Size `< 200_000` bytes → throw with preview
- Magic bytes not MP3 (`0xFF 0xE0..`) / ID3 / MP4 (`ftyp`) → throw with preview

**Silent HTML-to-MP3 corruption is no longer possible.**

## STREAK SYSTEM v1 (v78 — COMPLETE & TUNABLE)

### The model

Three independent metrics:

| Metric | Meaning | When it changes |
|---|---|---|
| **Streak** | Consecutive days showing up | +1 per **daily attempt** (pass or fail) |
| **Points** | Skill / performance | + per correct answer, bonus on pass |
| **Power** | Extra attempts to grind | 3 free/day + up to 3 bonus via ads |

**Streak resets when you skip a day. Points never reset. Power resets daily.**

### Multi-streak architecture

- **Each player can have up to 3 active streaks.**
- **Default** (`genre_id = NULL`) — game-picked daily rotation. Can be started any time. Cannot be abandoned.
- **Genre streak** (`genre_id = X`) — player-picked. Can be abandoned. Abandoning **deletes its attempts** (fresh restart).
- **Power pool is shared** across all streaks (3 base + 3 bonus per day, total 6 max).

### The generator (`generator.js`)

- `ensureChallenge(env, dateStr, genreId = null)` — generate or fetch for (date, genre).
- **`genreId = null`** → game-picked rotation: rank viable genres by distinct track count, cycle by `(date - '2026-01-01') % genreCount`.
- **`genreId = X`** → player-picked: use that genre, same daily artist rotation.
- **`tracks` do NOT have `genre_id`.** Use `json_each(artists.genre_ids)`.
- **Artist pick is smart**:
  - Uses `COUNT(DISTINCT t.name)` (not rows — avoids counting multi-position clips twice)
  - Uses `COUNT(DISTINCT i.track_name)` for instruments
  - **Only requires lyrics if the challenge needs lyrics** (checks `PRESET_DECK` slice)
  - **Only requires instruments if the challenge needs instruments**
  - Top 30 by distinct track count
  - Seeded shuffle
  - **Anchor = #1 artist by track count** (always included for recognizability)
- **`buildConfig(seed)`** shuffles presets **within phases** (2 slots each) for daily variety while preserving escalation.

### The 12-slot escalation

```
Streak day 0 → 2 batches (warmup_track, warmup_artist)
Streak day 1 → 3 batches
Streak day 2 → 4 batches
Streak day 3 → 5 batches
...
Streak day 10+ → 12 batches (full deck)
```

Formula (client-side, from config):
```js
const easyMode = consecutiveFailures >= config.easyModeFailures;
const totalBatches = easyMode
  ? config.earlyBatches
  : Math.min(streakDay + config.earlyBatches, config.lateBatches);
const maxTotalQuestions = easyMode
  ? config.easyModeTotalQuestions
  : Math.min(config.baseTotalQuestions + streakDay * config.perDayMultiplier, config.maxTotalQuestions);
const questionsPerBatch = Math.max(
  config.minQuestionsPerBatch,
  Math.min(config.maxQuestionsPerBatch, Math.floor(maxTotalQuestions / totalBatches))
);
```

**Easy mode** (3+ consecutive fails): `earlyBatches` warm-up batches. Pass resets failures to 0.

### Points formula

**Per-attempt points:**
- **Daily:** `round(correct × pointsPerCorrect × totalMultiplier) + dailyPassBonus` on pass
- **Power:** `round(correct × pointsPerCorrectPower) + powerPassBonus` on pass

**`totalMultiplier`** = `levelMultiplier × genreMultiplier`:
- `levelMultiplier`: from `CHALLENGE_CONFIG.levelMultipliers` (1.0 / 1.2 / 1.5)
- `genreMultiplier`: `defaultGenreMultiplier` (1.5×) for Default, `1.0` for genre streaks

**Critical:** `challenge.config` is a JSON **string** in D1. Must be `JSON.parse()`d before passing to `totalMultiplier`.

### `submitAttempt` flow (correct order)

1. Validate input + `genre_id`
2. Verify challenge exists for (date, genre)
3. Fetch specific `profile_streaks` row
4. Check shared power limit (summed across all streaks)
5. Compute points
6. **INSERT `challenge_attempts` FIRST** — UNIQUE constraint = source of truth
7. Compute streak + failure changes
8. Upsert `profile_streaks`
9. Update `profiles.total_points`

**`IS` operator** (not `=`) for NULL matching:
```js
'SELECT * FROM profile_streaks WHERE profile_id = ? AND genre_id IS ?'
```

### Streak logic

```js
if (mode === 'daily') {
  if (lastDate === yesterday)   newStreak += 1;
  else if (lastDate !== dateStr) newStreak = 1;
  if (passed) newFailures = 0;
  else        newFailures += 1;
}
```

**Power doesn't touch streak or failures.**

### Abandon behavior

```js
async function abandonStreakHandler(request, env, params) {
  // ... verify streak exists ...

  await env.DB.batch([
    env.DB.prepare('DELETE FROM challenge_attempts WHERE profile_id = ? AND genre_id = ?')
      .bind(profileId, genreId),
    env.DB.prepare('DELETE FROM profile_streaks WHERE profile_id = ? AND genre_id = ?')
      .bind(profileId, genreId),
  ]);

  // Points stay in profiles.total_points (shared currency)
  // challenges rows stay (shared config, not per-profile)

  return json({ ok: true });
}
```

**Abandon deletes attempts too** — restarting the genre gives a clean slate (no "Daily done" ghost).
