The --branch=production flag updates the stable URL. Without it, you get a throwaway preview URL.

cmd
cd E:\matb3aa-game\music-game-wrangler

When you're ready for a real domain:

Buy a domain (odd-track.com, matb3aa-game.com, whatever).

Add it to Cloudflare (free plan).

In the Pages dashboard → music-game project → Custom domains → Add → enter the domain.

Cloudflare auto-configures DNS + SSL. Zero code changes.

The CORS_HEADERS in your Worker already has Access-Control-Allow-Origin: *, so the new domain will work immediately. Same for the _redirects file — SPA routing already handled.

Nothing in the code needs to change when you go from *.pages.dev to a custom domain. That's the whole point of doing it this way.
